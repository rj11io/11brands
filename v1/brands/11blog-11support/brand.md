# blog.rj11.io

Blog-hosted content in the palette of `11support`. The masthead stays blog.rj11.io while the colours identify the leading brand.

## Palette decision

Mode light. Signal `#EC4899` on ground `#FAFAFA`: **3.38:1**.

Colours are `11support`'s pink 500, unmodified — see that brand.md for the
two-round selection and the floor-only caveat (3.38:1), which this brand
inherits in full. This key exists because content cards carry their consuming
domain: generating against `11support` directly would put support.rj11.io on a
blog.rj11.io asset.

## Notes

Text is 11blog's; colours are not. Favicon packs are byte-identical to `11support`'s, so this brand usually only needs og-content. The signal must never be set as text — see `11support`'s notes.
