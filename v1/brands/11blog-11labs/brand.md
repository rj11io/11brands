# blog.rj11.io

Blog-hosted content in the palette of `11labs`. The masthead stays blog.rj11.io while the colours identify the leading brand.

## Palette decision

Mode light. Signal `#EA580C` on ground `#FAFAFA`: **3.41:1**.

Colours are `11labs`'s orange 600, unmodified — see that brand.md for the
selection round and, importantly, its floor-only caveat (3.41:1), which this
brand inherits in full. This key exists because content cards carry their
consuming domain: generating against `11labs` directly would put labs.rj11.io on
a blog.rj11.io asset.

## Notes

Text is 11blog's; colours are not. Favicon packs are byte-identical to `11labs`'s, so this brand usually only needs og-content. The signal must never be set as text — see `11labs`'s notes.
